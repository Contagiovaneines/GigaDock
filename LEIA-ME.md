# Como usar no Antigravity

1. Extraia este ZIP e abra a pasta `dock-windows-antigravity` como projeto no Antigravity.
2. Instale as ferramentas do arquivo `instalar-dock-windows.bat` antes da etapa 04, se ainda não estiverem instaladas.
3. No chat do agente, envie: `Leia AGENTS.md e execute prompts/01-analisar.md. Salve o resultado em docs/ e atualize docs/STATUS.md.`
4. Confira o resultado. Depois peça `prompts/02-design.md`, e prossiga na ordem até `07-entregar.md`.
5. Se quiser uma tentativa contínua, envie: `Leia AGENTS.md e execute os arquivos prompts/01 a 07 em ordem, consultando docs/STATUS.md entre etapas. Pare se houver bloqueio real, falha de build ou decisão que mude o escopo.`

Os arquivos Markdown não iniciam tarefas por conta própria. A execução começa quando você dá a instrução no chat. As etapas de build e teste devem ocorrer em Windows.
