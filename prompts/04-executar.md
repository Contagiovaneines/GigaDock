# Etapa 04 — Implementação

Leia AGENTS.md, docs/01-analise.md, docs/02-design.md, docs/03-plano-tecnico.md e docs/STATUS.md. Implemente as entregas do plano, compilando após cada uma. Não pare após criar apenas a estrutura.

A versão funcional deve permitir: barra flutuante configurável; ambientes Trabalho, Estudos e Pessoal; criar, renomear, excluir e alternar; adicionar/abrir/reordenar/remover executáveis, arquivos, pastas e URLs; relógio; Pomodoro; temas claro e escuro; preferências locais; menu de configurações e sair; opção de iniciar com Windows; atalhos configuráveis; tratamento de erros e navegação por teclado.

Use APIs documentadas. Não esconda a barra de tarefas nem manipule janelas externas. Se uma integração falhar, mantenha as demais funcionais e registre limite real. Faça commits locais pequenos somente se o repositório já tiver Git e isso se encaixar no fluxo existente; não publique remotamente.

Entregue código executável, README com comandos, `docs/04-implementacao.md` com funcionalidades e decisões, resultados reais de build e docs/STATUS.md atualizado.
